Files and exports

The project

A project is one .ecam file (JSON): the master, every axis, the outputs, the mechanics and the drawing. File › Save / Save as; Open recent lists the last ten.

The project travels with the upload. Uploads carry a compressed copy of the whole project, so Download gives back exactly what was uploaded, mechanics and limits included.

Exports

File menuWrites
Export table (CSV)…The selected axis sampled over one cycle: master position, master counts, position, motor counts, velocity, acceleration.
Export table (C header)…The same as an int32_t table of motor counts, for a first firmware experiment.
Export cam DXF…A crank axis's plate cam (DXF R2000, in mm or inches): outline, pitch curve, base circle, optional bore, marks and notes, each on its own layer.
Export path DXF…The current axis's path (DXF R2000, in mm or inches): its position over one cycle as a polyline, with axes, ticks and notes. Across: on a timeline axis, so much per second (40 mm/s, or 10 in/s, to begin with); on a crank axis, a scale picked so the drawing is about twice as wide as it is tall, at an easy value such as 1 deg = 0.1 mm. Either is written in the notes. Also in the Axis menu and an axis's right-click menu in the project tree.
Export workbook (Excel)…The whole project as one .xlsx with tables and charts (below).
Generate report… (Ctrl+R)A PDF for reviewing the project (below); it opens when written.

DXF units: both DXF exports draw lengths in mm or inches, converted from the axis's units, and set the drawing's units to match. An axis in degrees, revolutions or counts is drawn as it is, unitless. A path DXF's notes also carry a line beginning ECW-PATH with its scales, for reading the path back.

The Excel workbook

One workbook, ready to share or archive:

  • Summary: every check, the axes at a glance (stroke, peaks, motor rpm, step rate), the master, links to each sheet.
  • Master: the master settings, the speed the project allows and why, the output pulses.
  • Timing: crank and timeline axes overlaid, and the output lanes, as charts.
  • Per axis: Profile (settings, segments with their peaks, analysis), Motion (sampled position, velocity, acceleration, jerk, with a chart of each) and, for crank axes, Cam (outline to scale and pressure angle).

The project report

A PDF for the engineer who reviews the project before it runs, laid out for print (Letter or A4 by your region) and drawn as vector graphics, so it stays sharp at any zoom:

  • Cover: the review status (errors and warnings), key figures (crank speed and headroom, cycle time, axes, outputs, peak motor speed) and the contents.
  • System overview: a block diagram of the master, the ClearCore, each axis and the outputs, and which motor connector and pin does what.
  • Timing diagram: every axis on its master, the output pulses below.
  • Machine cycle: a flow chart of the cycle, one step for each stretch where nothing changes: which axes move (from, to, law), which hold, which outputs are on, and how long it takes.
  • Master, then per axis: settings beside results, its checks, the segment table, the displacement diagram with velocity, acceleration and jerk (limits and peaks marked), and for a crank axis the plate cam and its pressure angle.
  • Outputs, every check, and a review and sign-off page with a checklist, notes and signature lines.

The figures and checks are the same as in the app and the workbook.
